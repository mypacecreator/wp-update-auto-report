# WP Update Auto Report

WordPress コア・プラグイン・テーマのアップデート差分を記録し、クライアント提出用の月次作業報告書（Markdown）を管理画面から生成するプラグインです。

---

## 必要環境

- WordPress 6.0 以上
- PHP 7.4 以上

---

## インストール

### ZIP インストール（推奨）

1. [Releases](https://github.com/mypacecreator/wp-update-auto-report/releases) から最新の ZIP をダウンロード
2. WordPress 管理画面 ＞ **プラグイン ＞ 新規追加 ＞ プラグインのアップロード** から ZIP をインストール
3. プラグインを有効化

### Git クローン

```bash
cd wp-content/plugins/
git clone https://github.com/mypacecreator/wp-update-auto-report.git
```

有効化は管理画面 ＞ **プラグイン** から行ってください。

---

## 使い方

### 基本の流れ（2ステップ）

**STEP 1 — アップデート前**

1. 管理画面 ＞ **ツール ＞ WP レポート生成** を開く
2. **「現在の状態をスナップショット」** ボタンをクリック
3. 「スナップショット取得済み（日時）」と表示されたことを確認

**STEP 2 — アップデート後**

4. 通常のアップデート作業（コア・プラグイン・テーマ）を実施
5. フロントエンドやフォームを目視で確認
6. 再度 **ツール ＞ WP レポート生成** を開く
7. 「差分プレビュー」で更新内容を確認
8. **「レポートを生成する」** ボタンをクリック
9. 表示された Markdown テキストをコピーまたはダウンロード

### コピー・ダウンロード

| ボタン | 動作 |
|--------|------|
| **リッチテキストでコピー** | Word や Google Docs にそのまま貼り付け可能な形式でコピー |
| **Markdown でダウンロード** | `report_YYYYMMDD.md` ファイルとしてローカルに保存 |

> **注意:** 「リッチテキストでコピー」は Clipboard API（HTTPS 環境）が必要です。HTTP 環境ではテキストとしてコピーされます。

## よくある質問

**Q. スナップショットを取り忘れてアップデートしてしまった**  
A. スナップショット未取得の場合、「レポートを生成する」ボタンは無効化されレポートを生成できません。アップデート内容を手動で記録し、次回からは必ず STEP 1 を先に行ってください。

**Q. テーマのアップデートも記録されますか？**  
A. はい。インストール済みの全テーマ（有効・無効問わず）のバージョンを記録・比較します。

**Q. スナップショットのデータはどこに保存されますか？**  
A. WordPress の `wp_options` テーブル（オプション名: `wuar_version_snapshot`）に保存されます。

**Q. AIによる詳細レポートは生成できますか？**  
A. 現バージョン（Phase 1）では固定フォーマットのみです。将来の Phase 2 で WordPress 7.0 の Connectors API（`wp_ai_client_prompt`）を使った詳細レポート生成機能を追加予定です。
