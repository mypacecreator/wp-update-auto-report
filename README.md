# WP Update Auto Report

WordPress コア・プラグイン・テーマのアップデート差分を記録し、クライアント提出用の月次作業報告書（Markdown）を管理画面から生成するプラグインです。

---

## 必要環境

### 基本機能（固定フォーマットレポート）

- WordPress 6.0 以上
- PHP 8.0 以上

### AI詳細レポート生成（オプション）

- Anthropic API キー
- Claude モデル（Opus 4.8 / Sonnet 4 / Haiku）

---

## インストール

### ZIP インストール（推奨）

1. [Releases](https://github.com/mypacecreator/wp-update-auto-report/releases) から最新の ZIP をダウンロード
2. WordPress 管理画面 ＞ **プラグイン ＞ 新規追加 ＞ プラグインのアップロード** から ZIP をインストール
3. プラグインを有効化

### Git クローン

```bash
cd wp-content/plugins/
git clone https://github.com/mypacecreator/wp-update-auto-report.git
```

有効化は管理画面 ＞ **プラグイン** から行ってください。

## 使い方

### 基本の流れ（3ステップ）

**STEP 1 — アップデート前**

1. 管理画面 ＞ **ツール ＞ WP レポート生成** を開く
2. **「現在の状態をスナップショット」** ボタンをクリック
3. 「スナップショット取得済み（日時）」と表示されたことを確認

**STEP 2 — アップデート後**

4. 通常のアップデート作業（コア・プラグイン・テーマ）を実施
5. フロントエンドやフォームを目視で確認
6. 再度 **ツール ＞ WP レポート生成** を開く
7. 「差分プレビュー」で更新内容を確認
8. レポートを生成（スナップショットは保持されるため、どちらも何度でも生成可能）
   - **「レポートを生成する」** — 固定フォーマットの簡易レポート（即座に生成）
   - **「AI詳細レポートを生成」** — リリースノート付き詳細レポート（WordPress 7.0以上で表示）
9. 表示された Markdown テキストをコピーまたはダウンロード

**STEP 3 — 作業完了後**

10. **「スナップショットをリセット」** ボタンをクリックしてスナップショットを削除
    - リセットしないと、次回のスナップショット取得まで古い差分が残り続けます
    - リセット後はページが自動でリロードされ、STEP 1 の状態に戻ります

### コピー・ダウンロード

| ボタン | 動作 |
|--------|------|
| **リッチテキストでコピー** | Word や Google Docs にそのまま貼り付け可能な形式でコピー |
| **Markdown でダウンロード** | `report_YYYYMMDD.md` ファイルとしてローカルに保存 |

> **注意:** 「リッチテキストでコピー」は Clipboard API（HTTPS 環境）が必要です。HTTP 環境ではテキストとしてコピーされます。

## AI詳細レポート生成機能

**Anthropic API** を使用し、各アップデートのリリースノートを自動取得してAIが詳細レポートを生成します。

### セットアップ

1. **Anthropic API キーを取得**
   - [Anthropic Console](https://console.anthropic.com) でアカウント作成
   - API キー（`sk-ant-...`）を生成

2. **プラグインで設定**
   - 管理画面 ＞ **設定 ＞ WP Report AI Settings**
   - API キーを入力
   - モデルを選択（Opus 4.8 / Sonnet 4 / Haiku）
   - **「接続テスト」** ボタンで動作確認

3. **レポート生成**
   - ツール ＞ WP レポート生成 ＞ **「AI詳細レポートを生成」** ボタンをクリック
   - Claude がリリースノート付き詳細レポートを生成

### モデル選択ガイド

| モデル | 特徴 | 用途 |
|--------|------|------|
| **Claude Opus 4.8** | 最高性能、最大トークン | 複雑な分析・詳細報告書 |
| **Claude Sonnet 4** | バランス型 | 標準的なレポート生成 |
| **Claude Haiku** | 最速・最安価 | 高速処理・コスト削減 |

### 仕組み

1. **リリースノート自動取得**
   - WordPress.org API からコア・プラグイン・テーマのリリースノートを取得
   - 24時間キャッシュで高速化（Transient使用）
   - 非公開プラグインや取得失敗時は「（取得できませんでした）」として処理

2. **AIレポート生成**
   - 差分データ + リリースノートをプロンプトテンプレートに展開
   - Anthropic API で非技術者向けレポートを生成
   - セキュリティ・安定性・機能面の改善を簡潔に説明

### プロンプトテンプレートのカスタマイズ

運用者は `templates/prompt-ai-report.md` を編集してAIへの指示内容をカスタマイズできます。

**編集例:**

```bash
cd wp-content/plugins/wp-update-auto-report/
nano templates/prompt-ai-report.md
```

**テンプレート内のプレースホルダー:**

- `{diff_and_notes}` — 差分データとリリースノートが自動展開されます

ファイルが存在しない場合はデフォルトテンプレートが使用されます。

### 注意事項

- **プラグインslug推測の制約**: プラグイン名からslugを推測するため、一部のプラグインではリリースノート取得に失敗する場合があります
- **処理時間**: AIレポート生成には数秒〜数十秒かかる場合があります
- **費用**: Connectors APIの利用料金はプロバイダーの規約に従います

## よくある質問

**Q. スナップショットを取り忘れてアップデートしてしまった**  
A. スナップショット未取得の場合、「レポートを生成する」ボタンは無効化されレポートを生成できません。アップデート内容を手動で記録し、次回からは必ず STEP 1 を先に行ってください。

**Q. テーマのアップデートも記録されますか？**  
A. はい。インストール済みの全テーマ（有効・無効問わず）のバージョンを記録・比較します。

**Q. スナップショットのデータはどこに保存されますか？**  
A. WordPress の `wp_options` テーブル（オプション名: `wuar_version_snapshot`）に保存されます。

**Q. AIによる詳細レポートは生成できますか？**
A. はい。Anthropic API キーを設定することで、「AI詳細レポートを生成」ボタンが表示されます。このボタンをクリックすると、各アップデートのリリースノートを自動取得し、非技術者向けに分かりやすく説明した詳細レポートが Claude により生成されます。

**Q. Anthropic API キーを取得するには？**
A. [Anthropic Console](https://console.anthropic.com) でアカウント作成後、API キーを生成してください。キーの形式は `sk-ant-...` です。管理画面 ＞ 設定 ＞ WP Report AI Settings で設定可能です。

**Q. どのモデルを選べばよいですか？**
A. 推奨は **Claude Opus 4.8**（最高性能）です。コスト削減したい場合は **Claude Sonnet 4** または **Claude Haiku** を選択してください。各モデルの詳細は上記のモデル選択ガイドを参照してください。

**Q. AIレポート生成に失敗した場合はどうなりますか？**
A. エラーメッセージが表示され、レポートは生成されません。この場合、以下を確認してください：
- Anthropic API キーが正しく設定されているか
- API キーの有効期限や利用制限に達していないか
- 接続テストが成功しているか（管理画面 ＞ 設定 ＞ WP Report AI Settings）
- ネットワーク接続が正常か

失敗時はスナップショットはリセットされないため、再度「AI詳細レポートを生成」または「レポートを生成する」を試すことができます。
